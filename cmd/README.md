# `cmd` directory

This directory contains executable commands and tool suites for `gomoqt`.

## Subdirectories

- [`cmd/interop/`](interop/): Interoperability testing server and clients for testing Media over QUIC (MOQ Lite) implementations over WebTransport and native QUIC.
  - `cmd/interop/server`: Go-based interop server.
  - `cmd/interop/client`: Go-based interop client.
